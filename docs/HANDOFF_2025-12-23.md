### 如果遇到问题

#### 1. Unity 编译错误：找不到 ILoadingTelemetry
**原因：** Unity 还没有编译新创建的文件  
**解决：** 等待 Unity 自动刷新，或手动 Assets → Refresh

#### 2. VContainer 依赖注入失败
**原因：** `LoadingService` 需要 `ILoadingTelemetry` 参数  
**解决：** 确认 `CoreLifetimeScope.cs` 中已注册 `LoadingTelemetry`

#### 3. 子模块处于分离头指针状态
**原因：** Git 子模块默认行为  
**解决：**
